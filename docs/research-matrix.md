# Research matrix — completed before numerical implementation

Reviewed: **2026-10-16**. Baseline: **Blender 5.2 LTS**, English UI, default keymap. Extension baseline: **3D Print Toolbox 1.4.1**. Meshy plugin documentation explicitly lists Blender 5.2.0 as tested. This is documentary research, not a claim of hands-on validation in Blender.

## Evidence policy

**OFFICIAL / DOCUMENTED** establishes operator behavior, UI names, and parameter meaning. **HEURISTIC / PRACTICAL STARTING POINT** establishes the guide's explicitly authored trial procedure. A linked manual does not endorse our numerical formulas. No setting is guaranteed safe. No geometry is inspected by this application.

Manual pages were located through current search-indexed Blender 5.2 documentation. Full-page retrieval of Blender's site was blocked in this environment; therefore these entries record indexed-document verification, not a complete manual audit. Meshy documentation was retrieved in full. Source URLs using `latest` were titled Blender 5.2 LTS on the review date; the application records the researched version separately. Installation and exporter details were cross-checked against the extension catalogue and official format index. Live Blender UI verification remains outstanding.

Secondary material is supplementary reading only; it does not determine settings. Where no relevant second source was verified, the matrix says so instead of inventing one. Official FDM manufacturers' material is primary evidence for their own process, not Blender's UI.

## Handoff and boundaries

- [Units](https://docs.blender.org/manual/en/latest/scene_layout/scene/properties.html) and [Apply](https://docs.blender.org/manual/en/latest/scene_layout/object/editing/apply.html): metric units and displayed mm do not by themselves rescale existing geometry. Enter intended physical dimensions; inspect with measurement; apply Scale after resizing a duplicate.
- [STL](https://docs.blender.org/manual/en/latest/files/import_export/stl.html): native File → Export → STL (.stl). [OBJ](https://docs.blender.org/manual/en/latest/files/import_export/obj.html): native Wavefront (.obj). [Format index](https://docs.blender.org/manual/en/latest/files/import_export/index.html) does not list native 3MF. Do not promise Blender-native 3MF; export STL then save a 3MF project in the slicer. Meshy's web export offering is separate from Blender's exporters.
- Use a documented millimetre workflow: Metric, Unit Scale 0.001, Length Millimeters; enter final dimensions explicitly. With resulting raw coordinates in mm, native STL Scale 1 and Scene Unit **off** preserves those coordinate numbers for slicers interpreting STL in mm. This is a mathematical unit-conversion recipe, not an unconditional exporter preset: reimport and verify all three dimensions. Other scene conventions require a different factor. Toolbox 1.4.1 Export Units is a distinct extension control; do not confuse it with native STL Scene Unit or Meshy Scene Scale.
- [Meshy introduction](https://docs.meshy.ai/en/webapp/plugins/blender/introduction), [cleanup](https://docs.meshy.ai/en/webapp/plugins/blender/model-cleanup), [analysis](https://docs.meshy.ai/en/webapp/plugins/blender/model-analysis), [export](https://docs.meshy.ai/en/webapp/plugins/blender/model-export), [hollow-model help](https://help.meshy.ai/en/articles/13835793-how-do-i-fix-a-hollow-meshy-model-for-3d-printing): plugin optional; no API key required by this guide. Run Analyze before and after selective repairs. Make Manifold is a plugin/extension action, not a built-in Blender Clean Up command. Delete Small Pieces thresholds may be in cm, cm² or cm³; never relabel those as mm or actual solid volume.
- [Bambu Fix Model](https://wiki.bambulab.com/en/software/bambu-studio/fix-model) and [Bambu Studio source](https://github.com/bambulab/BambuStudio): automatic repairs do not replace inspecting changed geometry. Windows-specific enhanced repair availability must not be promised on every OS. After import, check dimensions, orientation, walls, islands, unintended gaps and supports layer by layer.
- [Prusa modelling guidance](https://help.prusa3d.com/article/modeling-with-3d-printing-in-mind_164135) and [Formlabs wall-thickness discussion](https://formlabs.com/blog/minimum-wall-thickness-3d-printing/): process/material/nozzle matter. Do not transfer SLA/SLS minimum-wall tables to FDM.
- CAD escalation is requirement-based: exact dimensions, fit, cylindrical cavity, hole/shaft interface, snaps, critical flatness or repeatable parameters. Decorative organic work stays in Blender regardless of product category. Load-critical/heat-critical/contact-critical use requires separate engineering review, not a guessed “strong enough” thickness.

## Research conclusions that govern the implementation

1. A closed surface enclosing a volume can look empty in a viewport and still be a valid solid for slicing. Infill is selected by the slicer. A deliberately wall-thickened cavity is a separate case.
2. Opening, intentional cavity and normal error require different follow-up questions. “See through” alone cannot diagnose a hole.
3. Floating intentional hair must be joined or rebuilt, not deleted as debris. Delete Loose is not a disconnected-island remover.
4. Remesh is gated behind backup, known geometry state, feature preservation and dimensional requirements. Expensive grids must prompt a local test rather than automatic aggressive values.
5. A valid “no universal starting number” is preferable to unsupported precision.
6. No source claims the guide's heuristics are official Blender defaults or experimentally calibrated FDM guarantees.
